# 就活Doc自動生成 - GAS Webアプリ

会社名や選考フェーズ、設問を入力すると、就活対策に必要な6本のGoogle Document（企業研究・アピールポイント・想定Q&A・ES自動最適化・逆質問など）をGoogle Gemini APIを活用して一括自動生成するGoogle Apps Script（GAS）Webアプリケーションです。

---

## 📁 ファイル構成

```
syukatu/
├── appsscript.json        # プロジェクト設定・Webアプリ権限設定
├── .clasp.json            # clasp（GAS同期ツール）の設定ファイル
├── Config.js              # 全体設定（Geminiモデル、トークン、フォルダ名、制限値）
├── GeminiClient.js        # Gemini API連携（エラーリトライ・トークン計測）
├── DocService.js          # Google Driveフォルダ管理・Doc生成・テキスト整形差し込み
├── Main.js                # エントリーポイント（doGet, 入力サニタイズ, 全Stepオーケストレーション）
├── SelfAnalysis.js        # 自己分析データ（ユーザー固有の経歴・強み等）
├── Step1.js               # Step1: 参考URLまとめ（一次情報URL厳選・CSE検索）
├── Step2.js               # Step2: 会社概要・競合差別化・選考対策
├── Step3.js               # Step3: 自己分析×企業の接続・アピールポイント
├── Step4.js               # Step4: 想定質問返答集（面接Q&A・圧迫面接対策）

├── Step6.js               # Step6: 評価を上げる刺さる逆質問集
├── Ui.html                # WebアプリUI（フロントエンド画面・リアルタイム進捗表示）
└── README.md              # 本ドキュメント
```

## 🚀 はじめに：初期セットアップ手順（ローカル環境からの導入）

本プロジェクトを各自の環境で動かすための手順です。

### 1. 前提条件の準備
- **Node.js** がインストールされていること
- **Google アカウント** を持っていること

### 2. Google AI Studio で Gemini API キーを発行
1. [Google AI Studio](https://aistudio.google.com/) にアクセスしてログインします。
2. 「**Get API key**」をクリックし、新しい API キーを発行して手元に控えておきます。

### 3. Google Apps Script（GAS）プロジェクトの作成と Script ID の取得
1. ブラウザで [Google Apps Script](https://script.google.com/) にアクセスします。
2. 左上の「**新しいプロジェクト**」をクリックします。
3. プロジェクト名を「`就活Doc自動生成`」などに変更します。
4. 画面左側のメニューにある「**⚙ プロジェクトの設定**」を開きます。
5. **スクリプト ID**（Script ID: 英数字の文字列）をコピーします。
6. 同画面内の「**スクリプト プロパティ**」セクションで「**プロパティを追加**」をクリックし、以下を設定して保存します：
   - **プロパティ（キー）**: `GEMINI_API_KEY`
   - **値**: 手順2で発行した Gemini API キー

### 4. ローカル環境の設定（clasp のインストールとログイン）
ターミナルまたは PowerShell を開き、以下のコマンドを実行します。

```bash
# clasp のグローバルインストール
npm install -g @google/clasp

# Google アカウントで clasp にログイン（ブラウザが開くので認証）
clasp login
```

※ Google Apps Script の [ユーザー設定画面](https://script.google.com/home/usersettings) で「Google Apps Script API」が **オン** になっていることを確認してください。

### 5. `.clasp.json` の設定
本リポジトリ直下の `syukatu/.clasp.json` を開き、手順3で取得した **Script ID** を記入します：

```json
{
  "scriptId": "ここに取得したScript IDを貼り付け",
  "rootDir": "",
  "scriptExtensions": [
    ".js"
  ],
  "htmlExtensions": [
    ".html"
  ],
  "jsonExtensions": [
    ".json"
  ],
  "filePushOrder": [],
  "skipSubdirectories": false
}
```

### 6. 自己分析データの登録
`SelfAnalysis.js` を開き、自身の学生時代のエピソード、自己PR、強み・弱み、価値観などを `content: \`...\`` の中に詳しく記述します。

```javascript
var SELF_ANALYSIS = {
  content: `
■ 基本情報
- 大学・学部：〇〇大学 〇〇学部
...
■ ガクチカ（学生時代に力を入れたこと）
...
`
};
```

### 7. コードを GAS に Push
`syukatu` ディレクトリで以下のコマンドを実行します：

```bash
clasp push
```

## 🌐 Webアプリのデプロイ・起動方法

### 初回デプロイ手順
1. ブラウザで GAS プロジェクトを開きます（ターミナルで `clasp open` を実行しても開けます）。
2. 右上の「**デプロイ**」→「**新しいデプロイ**」をクリックします。
3. 左側の歯車アイコンから「**ウェブアプリ**」を選択します。
4. 設定項目を以下のように指定します：
   - **説明**: `初回デプロイ`
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `自分のみ`（または必要に応じて `全員`）
5. 「**デプロイ**」ボタンをクリックします。
6. 初回のみ「**アクセスを承認**」画面が出ます。自身のアカウントを選択し、「詳細」→「就活Doc自動生成（安全ではないページ）に移動」→「許可」をクリックします。
7. 表示された **ウェブアプリ URL** にアクセスすると、入力フォーム画面が表示されます。

## 📝 各ステップのプロンプト役割とカスタマイズガイド

各ファイル（`Step1.js` 〜 `Step6.js`）は独立した役割を持ち、前段の出力結果を後段のコンテキストとして引き継ぐパイプライン構造になっています。

### 各 Step の役割一覧

| ファイル | 生成ドキュメント | 役割・出力内容 |
| :--- | :--- | :--- |
| **`Step1.js`** | `参考URLまとめ` | 企業の公式HP、IR資料、採用情報、社長インタビューなど信頼性の高い一次情報URLをリスト化（Google Custom Search連携可） |
| **`Step2.js`** | `会社概要まとめ` | 3分要約、主力事業、強み・ビジネスモデル、直近動向、競合他社比較マトリクス、差別化ロジック |
| **`Step3.js`** | `アピールポイント` | Step2の企業情報と自己分析を掛け合わせ、その企業に最も刺さる強み3選・接点・志望動機の三段論法・STARエピソードを抽出 |
| **`Step4.js`** | `想定質問返答集` | 自己分析系・志望動機系・企業理解系・人柄系に加え、企業特有質問や圧迫面接（意地悪質問）への切り返し対策Q&A |
| **`Step5.js`** | `ES自動最適化` | 志望動機(400字)、自己PR(400字)、ガクチカ(600字)等の完成ES。文字数配分と構成案→完成文章→文字数カウントの2段階生成 |
| **`Step6.js`** | `刺さる逆質問` | 人事面接／現場面接／役員・最終面接の各面接官タイプ別逆質問、企業特有の逆質問、応募者強みアピール型逆質問、NG質問集 |

### プロンプトを変更する際のコツ

1. **「最重要ルール」を崩さない**
   - AIのハルシネーション（幻覚・嘘の生成）を防ぐため、各 Step に記載されている `・推測禁止。不明な情報は必ず「不明」と記載。` `・入力情報のみを根拠にする。` は維持してください。
2. **出力フォーマットの構造（見出し構造）を指定する**
   - 生成結果を Google Docs に落とし込む際、`■` は見出し2（HEADING2）、`【...】` は見出し3（HEADING3）として自動装飾されます。見出し記号を活用すると読みやすいドキュメントが生成されます。
3. **文体や文字数の制御**
   - ESや回答集で「話し言葉（〜です、〜ます）」または「書類用（〜である、〜だ）」を指定したい場合は、各 Step のプロンプト内にある【文体ルール】を調整してください。

---

### プロンプト変更後のアップデート・反映手順

プロンプトやロジック（`.js` ファイル）を修正した後は、以下の2ステップで本番環境に反映します。

#### ステップ 1: コードの同期（clasp push）
```bash
clasp push
```

#### ステップ 2: GAS 側のデプロイ更新（重要）
※ GASの仕様上、コードを push しただけでは公開中の Web アプリ URL には反映されません。
1. ブラウザで GAS エディタを開きます（`clasp open`）。
2. 右上の「**デプロイ**」→「**デプロイを管理**」を開きます。
3. 左側のアクティブなデプロイを選択し、右上の **鉛筆アイコン（編集）** をクリックします。
4. **バージョン** ドロップダウンから「**新バージョン**」を選択します。
5. 「**デプロイ**」をクリックして完了です。

## ⚙️ オプション設定（Script Properties）

GAS の「プロジェクトの設定」>「スクリプト プロパティ」で以下の拡張設定が可能です。

| プロパティ名 | 必須 | 説明 | 設定例 |
| :--- | :---: | :--- | :--- |
| `GEMINI_API_KEY` | **必須** | Google AI Studio で発行した Gemini API キー | `AIzaSy...` |
| `SELF_ANALYSIS_CONTENT` | 任意 | `SelfAnalysis.js` を直接編集する代わりに、プロパティ側で自己分析を保持したい場合に設定 | 自身の自己分析テキスト |
| `CSE_API_KEY` | 任意 | Google Custom Search API キー（Step1の実検索用） | `AIzaSy...` |
| `CSE_ENGINE_ID` | 任意 | Google Programmable Search Engine ID | `0123456...` |
| `TEMPLATE_DOC_IDS_JSON` | 任意 | 書式やロゴ付きのGoogle Docテンプレートをベースにしたい場合の Doc ID マップ（JSON形式） | `{"COMPANY_OVERVIEW": "xxx", ...}` |

## ⚠️ トラブルシューティング

- **「GEMINI_API_KEY is not set in Script Properties.」と表示される**
  - GASエディタの「プロジェクトの設定」→「スクリプト プロパティ」に `GEMINI_API_KEY` が登録されているか確認してください。
- **「Exceeded maximum execution time」（6分タイムアウト）**
  - GASの1回あたりの実行時間上限（6分）を超えた場合に発生します。
  - 通常は2〜3分程度で完了しますが、Gemini APIの混雑状況によってリトライが重なると発生することがあります。時間をおいて再実行してください。
- **ドキュメントの保存場所**
  - 生成されたドキュメントは、Google Drive のマイドライブ直下に自動作成される「`就活Doc自動生成`」フォルダ内の企業別フォルダに整理されて保存されます。
